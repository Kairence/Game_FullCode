# Global AI Agent Rules & Core Constraints

## 1. 언어 및 소통 규칙
- 모든 답변, 설명, 코드 주석은 예외 없이 한국어로만 작성할 것.
- 모든 텍스트(위키, 코드, 대화 등 전체)에서 이모지(Emoji) 사용을 절대 금지함.
- 기획 단계(시스템 설계, 개념 논의 등)에서는 절대로 코드를 작성하지 말 것. 기획과 코딩 단계를 명확히 분리할 것.

## 2. 울티마 온라인(ServUO Custom Core) 시스템 제약 조건
- 서버 코어(Server 폴더)를 수정한 것이 아니라면 `Compile.WIN - Release.bat` 등 서버 컴파일 배치 파일을 절대 실행하지 말 것. `Scripts` 폴더 내의 수정은 런타임에서 재컴파일 되므로 배치 파일 실행이 불필요함.
- 순정 ServUO 시스템으로 유추하여 코드를 짜는 것을 절대 금지함. 기획 및 코드 작성 전 반드시 기존 커스텀 소스를 확인할 것.
- 캐릭터 스킬 상한은 기본 200으로 계산할 것.
- 모든 스탯(Stats)은 최소 1000부터 최대 9999까지의 범위를 가짐.
- 성능 최적화를 위해 기존의 Attributes 구조를 사용하지 않음. 대신 int 형식을 사용하는 자체 코드를 적용하며, 계산 스케일은 10000당 1%(0.01)로 처리할 것.
- 세이브/로드 핵심 구조: WorldSave 및 WorldLoad 처리는 반드시 Configure() 함수 내부에 위치시켜야 함. (Initialize() 함수는 커스텀 코어에서 작동하지 않음)

## 3. C# 코딩 표준 및 최적화 가이드라인
- 기본 환경: 특별한 요청이 없다면 .NET 8.0 (C# 10) 기준으로 작성할 것.
- 성능 및 가비지 컬렉션(GC) 최적화 최우선: ref, out, LINQ, 람다식(Lambda expressions)의 사용을 최대한 배제할 것.
- 메모리 및 속도 최적화를 위해 ValueTuple(tuplevalue), ReadOnlySpan(readspan) 등을 적극적으로 활용하여 코드를 작성할 것.
- 소스 코드 수정 범위가 넓거나 변경점이 많은 경우, 독단적으로 코드를 짜지 말고 반드시 사용자에게 먼저 수정을 진행해도 될지 허락을 맡을 것.
- 분석 중 기억이 소실되거나 참조가 끊긴 클래스/메서드가 발견되면, AI가 임의로 생성하지 말고 사용자에게 해당 원본 파일을 요청할 것.
- 코드를 사용자에게 출력하기 전, 내부적으로 컴파일 및 런타임 시뮬레이션을 거쳐 검증한 뒤 전달할 것.
- 코드 출력 결과물이 너무 길어지거나 사용자가 코드가 잘렸다고 언급할 경우, 코드를 파트별로 분할해서 출력할 것.

## 4. 텍스트 처리 및 Gump UI 구현 규칙
- 문자열 조합 (퀘스트, 시스템 메시지 등): 아이템 명칭을 문장 속에 조립할 때 하드코딩된 한글 텍스트(예: "철광석") 사용을 절대 금지함. 반드시 서버 메모리에 로드된 `ClilocData.GetString(item.LabelNumber)`를 호출하여 동적으로 가져올 것. (단, Mobile/몬스터는 구조상 예외로 두어 수동 매핑 허용)
- Gump UI 단독 출력: UI 화면에 아이템 이름만 단독 표기할 때도 `ClilocData.GetString(item.LabelNumber)`를 활용하여 AddLabel로 처리할 것. (단, 커스텀 아이템은 item.Name 사용)
- HTML 태그 처리: <BASEFONT>, <CENTER> 등의 HTML 태그가 포함된 텍스트 출력은 무조건 `AddHtml(x, y, w, h, text, false, false)`을 사용하고, 배경(Background)과 스크롤바(Scrollbar) 속성은 지시가 없는 한 false로 고정할 것.

## 5. 위키(Wiki) 및 데이터 명세 출력 규칙
- 사용자가 위키(Wiki) 형태로 코드를 요청하는 경우, 마크다운 렌더링이 되어 깨지지 않도록 반드시 마크다운 코드 블록(```markdown) 내부에 감싸서 출력할 것.
- 표 포맷 테이블 구조는 [ | 분류 | 세트 번호 | 포함 아이템 | ] 형태를 유지해야 하며, 포함 아이템 칸의 아이템 클래스명들은 콤마(,)로 구분하여 한 줄에 보기 좋게 나열할 것.
